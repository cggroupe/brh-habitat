# Audit UX/UI complet — BRH Habitat

> **Audit demandé** : 2026-05-08 par Philippe Gagnon
> **Auteur** : Claude Opus 4.7 (1M context)
> **Référentiel cible** : startup américaine SaaS prospection B2B + plateforme MLM marketing de réseau
> **Plateformes inspiration** : Stripe, Linear, Pipedrive, Apollo.io, Close, Notion, Vercel + MLM (Beachbody, doTerra, Total Life Changes)
> **Score actuel UX** : **5.4/10** · **Score cible** : 9/10

---

## 0. TL;DR — Verdict en 30 secondes

La plateforme a une base technique exceptionnelle (186 pages, 141 tables DB, 22 règles scoring v2 sur 59 306 prospects, RLS auditée, build 0 erreur, infra solide). **Le problème n'est pas technique, il est UX.**

**3 verdicts critiques** :

1. **Charte visuelle inconsistante** (8 shells × 8 palettes différentes : vert, slate, cyan, amber, orange, rouge → l'utilisateur a l'impression de naviguer entre 8 produits différents). Une startup US bien foutue = 1 palette + 1 accent semantique.

2. **Navigation surchargée** (sidebar agence à 19 entrées flat avant la refonte d'aujourd'hui, 13 sur ProShell, 13 sur ArtisanShell, 7 sur ReseauShell). Linear / Stripe / Pipedrive plafonnent à **5-7 top-level + groupes pliables**.

3. **Parcours MLM invisible** alors que le modèle BRH = MLM 5 niveaux. Pas de leaderboard public, pas d'arbre de réseau visualisé attractif, pas de gamification points/badges, pas de "share-to-earn" social. Si on veut faire 20k€ MRR M+12 (cible Phase 16), il faut **rendre le MLM désirable et viral** comme le font Beachbody / doTerra.

**Effort estimé refonte complète** : 8-12 jours dev (~70-90h), 0 changement DB requis, 0 régression fonctionnelle, 100 % gain UX.

### Composants UI bruyants

| Pattern actuel | Problème | Standard SaaS US |
|---|---|---|
| `bg-gradient-to-br from-X to-Y` partout (15+ occurrences) | Effet "années 2014 Material Design", pas premium | Solid color + 1 ombre subtile (Linear, Vercel) |
| `shadow-xl shadow-primary/20` sur Hero | Surcharge visuelle | `shadow-sm` ou no shadow + bordure 1px |
| `rounded-2xl` mélangé `rounded-xl` `rounded-lg` | Hiérarchie cassée | 1 token unique (Stripe = 8px partout) |
| Emojis fonctionnels (🔥💙✨⚡🌟⭐💎🚀🎉🛢️🪵❄️) | Pas pro B2B | Lucide React icons sobre (`Flame`, `Snowflake`) |
| `text-2xl font-display` headers | Lourd, prend place | `text-base font-semibold` ou `text-lg` (Stripe Dashboard) |
| Couleurs sémantiques mélangées (rouge=très chaud + rouge=erreur + rouge=danger DPE) | Confusion sémantique | 1 couleur = 1 sens |
| Texts loupes "Bonjour Philippe" "Charte partenaire active" "Modèle Hoguet « A »" | Verbosité | Ton concis, prioriser action (Pipedrive) |

## 3. Refonte charte graphique — proposition complète

### Système de design unifié

```css
/* === Palette unique BRH 2026 (refonte) === */

/* Brand */
--brh-green:           #1c7b1d;  /* Identité BRH (sparing use) */
--brh-green-deep:      #094114;  /* Sidebar background uniquement */
--brh-green-light:     #81c784;  /* Hover & selected states */

/* Neutres (90% de l'UI) */
--bg-canvas:           #fafaf9;  /* Page background */
--bg-surface:          #ffffff;  /* Cards */
--bg-subtle:           #f4f4f5;  /* Tableau zebra, hover lignes */
--bg-muted:            #e4e4e7;  /* Borders subtle */

--text-primary:        #18181b;  /* zinc-900 */
--text-secondary:      #52525b;  /* zinc-600 */
--text-tertiary:       #a1a1aa;  /* zinc-400 */

/* Accents sémantiques (1 couleur = 1 sens) */
--accent-success:      #22c55e;  /* Green 500 */
--accent-warning:      #f59e0b;  /* Amber 500 */
--accent-danger:       #ef4444;  /* Red 500 */
--accent-info:         #3b82f6;  /* Blue 500 */

/* Score Vente (sémantique métier — exception légitime) */
--score-tres-chaud:    #dc2626;  /* Red 600 — DOT/badge uniquement */
--score-chaud:         #ea580c;  /* Orange 600 */
--score-tiede:         #d97706;  /* Amber 600 */
--score-froid:         #71717a;  /* Zinc 500 */
```

### Règles de composition

| Élément | Règle stricte |
|---|---|
| **Backgrounds** | Toujours `bg-canvas` (page) ou `bg-surface` (cards). Jamais de gradient sauf hero marketing public. |
| **Bordures** | `border border-zinc-200` partout. Pas de shadow xl. |
| **Shadows** | `shadow-xs` (`shadow-sm` max) + `border 1px` à la place des `shadow-xl` |
| **Rayons** | `rounded-md` (8px) partout sauf bouton primary `rounded-lg` (10px) |
| **Espacements** | Grille 4pt : 4, 8, 12, 16, 24, 32, 48, 64. Tailwind = `gap-1, 2, 3, 4, 6, 8, 12, 16` (multiplie par 4). |
| **Texte** | 5 tokens : `text-xs (12)`, `text-sm (14)`, `text-base (16)`, `text-lg (18)`, `text-xl (20)`. Plus jamais `text-[10px]` `text-[11px]`. |
| **Headers page** | `text-lg font-semibold text-zinc-900` (pas `text-2xl font-display`) |
| **Boutons primary** | `bg-zinc-900 text-white hover:bg-zinc-800 rounded-lg px-4 py-2 text-sm font-medium` (style Linear / Stripe) |
| **Boutons secondary** | `bg-white border border-zinc-200 text-zinc-900 hover:border-zinc-300 hover:bg-zinc-50` |
| **Pills/badges** | `bg-{color}-50 text-{color}-700 border border-{color}-200 rounded-full px-2 py-0.5 text-xs font-medium` |
| **Icons** | Lucide React, taille 16 par défaut, 14 dans badges, 20 dans empty state. **Aucun emoji** dans UI pro. |
| **Animations** | `transition-colors duration-150` + `transition-transform`. Plus de `transform hover:scale-105`. |

### Typographie

| Token | Font | Usage |
|---|---|---|
| `font-display` (DM Sans) | À garder pour H1 page seul | Logo + Hero marketing public |
| `font-sans` (Inter) | **Tout le reste** | Dashboard, sidebar, KPI, body, boutons |
| `font-accent` (Bebas Neue) | Supprimer | Plus utilisé |

→ Une seule police pour 95% de l'UI, comme Stripe, Linear, Notion, Vercel.

### Inspiration visuelle 1:1

| Surface | Modèle |
|---|---|
| Sidebar | Linear (sidebar dark slate-900 + accent unique) |
| Dashboard cards | Stripe Dashboard (cards blanches + bordure + KPI tabular num) |
| Tableaux | Pipedrive (zebra subtile, sticky header, row hover, actions au hover) |
| Filtres | Apollo.io (chips horizontale + dropdown + saved views) |
| Onboarding | Notion (1 step à la fois, progress bar, skip optional) |
| Command palette | Linear/Vercel (Cmd+K → search routes/contacts/leads) |
| Empty states | GitHub (illustration vectorielle + 1 phrase + CTA) |
| Notifications | Sonner toast (top-right, auto-dismiss, action button) |

### Accessibilité (a11y) — score estimé 6/10

| Problème | Solution |
|---|---|
| Pas de `aria-label` sur boutons icon-only (StarOff favoris, NotificationBell) | Ajouter `aria-label` partout |

| Tableaux sans `<th scope="col">` | Audit table semantics |
| Modals sans `role="dialog" aria-modal="true"` | Utiliser Radix UI Dialog (a11y first) |
| Pas de `prefers-reduced-motion` respecté | Wrapper transitions avec `motion-safe:` Tailwind |
