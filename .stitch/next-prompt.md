Fiche entreprise/SCI individuelle pour BRH Habitat — afficher une personne morale (SCI, SARL, EURL) propriétaire d'adresses DPE, avec dirigeants, signaux BODACC, adresses détenues et succession potentielle.

**DESIGN SYSTEM (REQUIRED) :**

Fonts: Epilogue 600/700, Manrope 400/500/700, Material Symbols.
Background: champagne beige #fbf9f8.
Primary green BRH: #003404. Container: #e5eeff. Outline: #717a6c.

**Structure :**
1. Header sticky avec breadcrumb + bouton favoris + bouton "Voir le K-Bis"
2. Hero entreprise : dénomination Epilogue 700, SIREN mono, forme juridique chip, date création, capital social, activité libelle, badge "Active" vert ou "Radiée" rouge
3. Section "Dirigeants" : liste 1-3 cartes avec nom/prénom, qualité (Gérant/Président), date naissance, badge "Décédé" rose si applicable + lien fiche personne
4. Section "Adresses DPE détenues" : grille de cartes adresses avec étiquette DPE + surface + commune + lien fiche adresse
5. Section "BODACC alertes" : timeline verticale des publications (date, type avis, description, lien source)
6. Section "Succession potentielle" si dirigeant décédé : encadré rose-clair avec dates, héritiers identifiés, score succession
7. Sidebar droite : Scoring patrimoine SCI, signaux risque, lien Pappers/Société.com

Cohérent avec les 3 autres designs du projet (fiche-client-brh, fiche-adresse-dpe, liste-leads).
